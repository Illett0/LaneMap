# LaneMap（車線接続図ジェネレーター）

「走っている車線が先でどこへつながるか」を CSV から図にするツール。もとは京都・堀川通〜油小路通のために作ったが、どの道路にも使える。
車線数の増減だけでなく、**合流**・**右左折レーンの側道への離脱**・**途中から現れる車線**を描く。

- `render.py` … CSV → 自己完結の `lanes.html`（SVG 埋め込み、南行き／北行きをボタンで切り替え）。検証結果（lint）をコンソールに出す
- `editor.py` … 入力補助エディタ（ブラウザで編集すると、図と lint がその場で更新される）
- どちらも Python 3.10 以上・標準ライブラリだけで動く

## 使い方

```powershell
# 図を作る
python render.py horikawa-lanes.csv -o lanes.html
python render.py horikawa-lanes.csv -o lanes.html --strict   # エラーがあれば終了コード 1

# 入力補助エディタ
.\start-editor.ps1            # 起動してブラウザを開く（http://127.0.0.1:8765/）。CSV がなければ見出しだけの CSV を作る
.\stop-editor.ps1             # 止める
.\start-editor.ps1 -Csv samples\features-demo.csv -Port 8770   # 別の CSV を編集

# テスト
python -m unittest discover -s tests
```

## 入力 CSV

列: `方向,順,地点,種別,車線,接続,出典,確度,メモ`（＋任意の `交差道路`）

| 列 | 内容 |
|---|---|
| 方向 | `南行き` / `北行き` |
| 順 | 進行方向に沿った並び順（整数） |
| 地点 | 交差点名など |
| 種別 | `手前`（停止線の手前）/ `直後`（交差点を抜けた直後）/ `区間中` |
| 車線 | 進行方向に向かって左から、半角スペース区切り。`L` 左折専用 / `S` 直進 / `R` 右折専用 / `SL` / `SR` / `LSR` / `B` バス / `?` 不明。空欄は未入力 |
| 接続 | この行の車線が次の行でどうなるか（下記）。空欄なら自動補完 |
| 出典 | 自由記述 |
| 確度 | `確`（現地・ストリートビューで確認）/ `資`（資料にある）/ `推`（推定）/ 空欄（不明） |
| メモ | 自由記述 |
| 交差道路 | 任意。交差する通りの名前。側道へ離脱するときのラベルに使う（下記）。空なら「左折」「右折」と表示し、帯には地点名を出す |

`#` で始まる行は無視する。文字コードは UTF-8（BOM があっても読める）。

### 交差道路の書き方

| 書き方 | 意味 |
|---|---|
| `七条通` | 東西とも同じ名前 |
| `東:紫明通 西:鞍馬口通` | 東側と西側で名前が違う |
| `東:二条通` | 東側にしか道路がない（T字路）。道路のない側へ離脱すると警告する |

東西で書くので、南行き・北行きの行で同じ値を使える（南行きは左＝東、北行きは左＝西として読む）。
図では、交差点の帯を道路のある側にだけ伸ばし、東西の名前を帯の両端に出す。

### 接続の書き方

| 書き方 | 意味 |
|---|---|
| `1>1` | 1番目の車線が、次の行の1番目につながる |
| `2>2 3>2` | 2番目と3番目が、次の行の2番目に合流する |
| `1>@五条通` | 1番目が本線から離れて五条通へ抜ける。`1>@` と名前を省くと `交差道路` を使う |
| `1>@<五条通` / `1>@>五条通` | 離脱の向きを左／右に指定する（拡張。省略時は L だけなら左、R だけなら右、ほかは車線の位置で決める） |
| `3>x` | 3番目が行き先を指定せず途切れる（警告） |

- 次の行の車線で、どの接続の行き先にもなっていないものは「新しく現れた車線」として描く
- 通り名に空白は使えない（区切りと区別できないため）

### 接続が空欄のときの自動補完

- 同じ交差点の `手前` → `直後`: `S` を含む車線を左から順に1対1で対応させる。`L` だけの車線は左、`R` だけの車線は右の側道へ離脱させる
  - `S` を含む車線の数が前後で違うときは、**警告を出して対応を決めない**（図には「対応未定」と描く）
  - `B`・`?` の車線は自動で決めない（警告）
- 交差点をはさまない行どうし（`直後`/`区間中` → `手前`/`区間中`）: 車線数が同じなら左から1対1。違えば警告を出して決めない
- それ以外（`直後` の行がないまま交差点をまたぐ、など）: 警告を出して決めない
- 最後の行に書いた `1>1` のような次の行への接続は、警告を出して使わない（側道への離脱は書ける）

**データは補完しない。** 空欄は「未入力」、決められない接続は「対応未定」として描き、推測では埋めない。

## 図の読み方

- 北が上になるように、南行きは上から下へ、北行きは下から上へ進む（方向を切り替えると上下が反転する）
- 北行きは運転者の左が画面の左になる（矢印は路面標示どおり上向き）
- 南行きは向きを2種類から選べる（北行きはどちらでも同じ図）
  - **上空から見た向き**（既定）: 下向きに走る運転者の左は画面の右になる。左折の離脱は画面の右へ曲がる
  - **CSV の並び順**: 車線1を画面の左に置く（左右は鏡像）
- 矢印は路面標示の記号（↰ ↑ ↱）を、図の進む向きに合わせて回したもの。バスは「バス」と表示する
- 交差点は灰色の横帯で示す。`手前` の行には停止線（黒い太線）を引き、左の欄に `手前`／`直後`／`区間中` を色分けして表示する
- 線の見た目は確度で変わる: `確` 濃い実線 / `資` 薄い実線 / `推` 破線 / 空欄 灰色の点線。行と行をつなぐ線は、前後の行のうち低いほうの確度で描く

## 入力補助エディタ

- 3列の画面。左: 交差点の一覧（`手前`／`直後` が並び、点の色で入力状況が分かる。名前で検索、「未入力あり」「警告・エラーあり」で絞り込み）、中: 入力フォーム、右: 図（クリックすると、その行を選ぶ）と検証結果
- 初めて開くと「使い方」を表示する（右上の「？ 使い方」でいつでも開ける）
- フォームは ① 車線 → ② 接続 → ③ 出典・確度 の順
  - ① 車線: 運転席から見た道路の形で表示する。ボタンで右端に追加し、車線をクリックして選べば置き換え・左右の移動・削除ができる。「前の行から写す」もある
  - ② 接続: ミニ図の下の段（この行）の車線を選び、上の段（次の行）の車線をクリックしてつなぐ。「左へ離脱」「右へ離脱」「途切れ」もある。何もしなければ空欄（自動補完）のままで、その結果を点線で見せる。点線の状態から1か所でも手直しすると、自動補完の結果を元にした手入力に切り替わる
  - どちらも「文字で編集する」を開けば、CSV と同じ書き方で直接書ける
- 行の追加・複製・上下の移動・削除をすると、`順` は自動で 1, 2, 3… と振り直す。`手前` の行の下に追加すると、同じ地点の `直後` の行ができる（車線などは空欄）
- 保存（Ctrl+S）すると次のことが起きる
  - 元のファイルを `history/backups/` に残す
  - 変更点を `history/changes.csv`（日時・操作・行・項目・変更前・変更後）に追記する
  - `lanes.html` を作り直す
- ファイルがエディタの外で書き換えられていたら、保存の前に知らせる（再読み込みするか、上書き保存するかを選ぶ）
- `#` のコメント行は、位置ごと残して書き戻す
- 元に戻すは Ctrl+Z、行の移動は Alt+↑↓、行を上下に動かすのは Alt+Shift+↑↓
- PID ファイル（`editor.pid`）で重複起動を防ぐ。ログは `logs/editor.out.log` / `logs/editor.err.log`（UTF-8。PowerShell 5.1 では `Get-Content -Encoding UTF8` で読む）
- 127.0.0.1 だけで待ち受ける

## ファイル構成

```
render.py            読み込み・検証・描画（CLI）
editor.py            入力補助エディタのサーバー
editor/index.html    エディタの画面
start-editor.ps1     エディタ起動（重複起動しない）
stop-editor.ps1      エディタ停止
samples/             動作確認用（dummy-lanes.csv = 依頼書のダミーデータ、features-demo.csv = 描画機能の見本。どちらも架空）
tests/               unittest
```

## データの置き場所

CSV・作った図（`lanes.html`）・編集履歴（`history/`）は利用者ごとのデータなので、git には入れない（`.gitignore` 済み）。
プロジェクト直下に好きな名前で CSV を置き、`.\start-editor.ps1 -Csv 名前.csv` で編集する。

## 描画のカスタマイズ

読み込み（`parse_csv_text` / `analyze`）と描画（`render_svg` / `render_html`）は関数で分けてある。
寸法は `render.G`、色は `SVG_STYLE`、矢印は `GLYPH` で変えられる。国道番号などの装飾は `render_svg` の「見出し」や「交差点」の部分に足す。
